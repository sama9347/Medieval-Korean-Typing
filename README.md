## ✨ 핵심 기능 (Key Features)

### 1. ⌨️ 친숙한 두벌식 옛글 오토마타 (2-Set Old Hangul IME)
- 별도의 복잡한 세벌식이나 전용 소프트웨어(한컴오피스 등) 설치 없이, 일반 PC/스마트폰 두벌식 자판 그대로 자연스럽게 옛한글을 조합합니다.
- **초성 / 중성 / 종성 분리 오토마타**: 자음과 모음의 결합 순서에 따라 음절을 자동 조합합니다.
- **순경음 완벽 지원**: 초성 순경음(`ᄫ`)뿐만 아니라 종성 순경음(`ᇦ`)까지 오류 없이 실시간 조합됩니다.
- **합용병서 및 각자병서 완벽 지원**:
  - `ㅳ`, `ㅄ`, `ㅶ`, `ㅷ`, `ㅺ`, `ㅼ`, `ㅽ`, `ㅴ`, `ㅵ`, `ᇚ` 등 중세국어 문헌에 등장하는 복합 자음군을 두벌식 연타로 손쉽게 입력합니다.
- **특수 옛자모 원클릭 입력 바**: 아래아(`ㆍ`), 반치음(`ᅀ`), 옛이응(`ᅌ`), 여린히읗(`ᅙ`), 방점(`·`, `:`)을 마우스 클릭으로 즉시 삽입할 수 있습니다.

### 2. 🛡️ 잔상 완전 차단 엔진 (Ghosting Prevention)
- 윈도우 기본 한글 IME(MS-IME)와 웹 브라우저의 `compositionstart / compositionupdate / compositionend` 간의 충돌로 인해 발생하던 **글자 밑줄, 글자 겹침, 잔상 현상을 100% 원천 차단**합니다.
- 영문 모드뿐만 아니라 **한글 모드 상태에서도 잔상 없이 매끄러운 타이핑**이 가능합니다.

### 3. 📍 모든 폰트 호환 전치 방점 (Preceding Tone Marks)
- 중세국어 성조 표기인 방점(· 거성, : 상성)을 글자의 **앞(좌측)**에 정확하게 배치하며, 커서 위치 이동 및 수정 시에도 음절 구조가 깨지지 않도록 정밀 제어합니다.

### 4. 🔄 유니코드 첫가끝 & 한양 PUA 이중 지원
- **유니코드 표준 첫가끝(U+1100 ~ U+11FF)**: 웹 표준 최신 브라우저 및 현대 시스템과 100% 호환.
- **한양 PUA(사용자 정의 영역 U+E000 ~ U+F8FF)**: 구형 한글 문서 및 특정 옛글 폰트(전주완판본, 한둥근체 등)와의 완벽한 렌더링 호환성을 위해 실시간 자동 상호 변환(`YetHangulIME.convertToHanyangPUA`)을 지원합니다.

### 5. 🎨 14종 옛한글 대표 서체 실시간 렌더링 비교 갤러리
입력한 텍스트가 각 서체에서 어떻게 표현되는지 한눈에 실시간 비교할 수 있습니다.

## 📥 폰트 다운로드 및 라이선스 센터 (`fonts-download.html`)

본 프로젝트는 저작권법을 엄격히 준수하기 위해 **폰트 파일의 무단 임의 재배포를 지양**하며, 정식 라이선스를 보유한 각 개발사 및 공공기관의 **공식 배포처 링크**를 체계적으로 정리하여 제공합니다.

- **원클릭 링크 복사**: 14개 공식 다운로드 링크를 한 번에 복사
- **OS별 설치 가이드 수록**: Windows 10/11 및 macOS 서체 등록 안내
- **라이선스 유형별 투명한 명시**: 공공누리 제1유형, SIL OFL, 비영리 무료 등

## ⌨️ 자판 입력 안내 (Keyboard Mapping)

| 입력할 자모 | 두벌식 자판 키 | 비고 |
|:---:|:---:|:---|
| **ㆍ (아래아)** | `Shift + A` 또는 자모 바 클릭 | 모음 조합에 활용 |
| **ᅀ (반치음)** | `Shift + Z` 또는 자모 바 클릭 | 옛 자음 |
| **ᅌ (옛이응)** | `Shift + X` 또는 자모 바 클릭 | 꼭지 달린 이응 |
| **ᅙ (여린히읗)** | `Shift + G` 또는 자모 바 클릭 | 된소리 부호 |
| **ᄫ (순경음 비읍)** | `ㅂ` + `ㅇ` 또는 자모 바 클릭 | 입술가벼운소리 |
| **· (거성 방점)** | `·` 버튼 클릭 | 1점 (높고 짧은 소리) |
| **: (상성 방점)** | `:` 버튼 클릭 | 2점 (낮았다가 높아지는 소리) |
| **한자 변환** | `F9` 키 | 한글 단어 커서 위치에서 F9 입력 |

## 🚀 빠른 시작 (Quick Start)

GitHub Pages에 접속하여 별도 설치 없이 즉시 사용할 수 있습니다:
👉 **[https://sama9347.github.io/Medieval-Korean-Typing/](https://sama9347.github.io/Medieval-Korean-Typing/)**

### 2. 로컬 실행
저장소를 클론한 후 `index.html`을 더블 클릭하여 실행합니다.
```bash
git clone https://github.com/sama9347/Medieval-Korean-Typing.git
cd Medieval-Korean-Typing
# 브라우저에서 index.html 열기
```
